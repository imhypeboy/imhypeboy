## 작업 방식

- **흐름부터 설계합니다.** 화면 사이의 연결과 로딩·빈 상태·오류 상황을 함께 살핍니다.
- **동작을 검증합니다.** 화면과 계산 로직을 분리하고, 날짜 경계와 데이터 규칙을 테스트합니다.
- **판단의 근거를 남깁니다.** 기술 선택과 문제 해결 과정은 프로젝트별 문서와 개발 사례에 정리합니다.
